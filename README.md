# SCT_WD_3 —QUIZ

A responsive React quiz with separate rounds for web development, general knowledge, maths, and science. Each round mixes single choice, multi-select, true or false, and fill-in-the-blank. Answers are collected as you go, then scored with a review at the end.

## Features

- Four categories, each with its own questions
- Four question formats in every round
- Move back and change an answer before you finish
- Multi-select scores only when every correct option is chosen and no extra option is selected
- Fill-in-the-blank ignores case and extra spaces
- Final score, a breakdown by question type, and a review of each answer
- Layout that stays readable on phones and wider screens

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints, usually `http://localhost:5174`.

## Build

```bash
npm run build
npm run preview
```
